# Steel Trading Desk
Native multiplatform utility for discretionary SPY and VXX options trading. — v1.0

![License](https://img.shields.io/github/license/ghostintheprompt/steel-trading-desk)
![Platform](https://img.shields.io/badge/platform-iOS%20|%20macOS-blue)

Steel Trading Desk is a local-first, manual-entry desk designed to bridge the gap between chart analysis and rigorous trade management. It focuses on high-probability institutional windows around the market open and close.

## Core Features

| Feature | Description |
| :--- | :--- |
| **Setup Validation** | Multi-factor checks for time windows, volume, VWAP, and volatility. |
| **Signal Intelligence** | Direction-aware alerting (WATCH, ENTRY, EXIT) with real-time monitoring. |
| **Prompt Coach** | Context-aware AI analysis prompts pre-filled with your manual market data. |
| **Boiler Room UI** | High-contrast Obsidian & Electric aesthetic designed for rapid tape reading. |
| **Local-First** | Zero telemetry. Zero latency. All data stays on your hardware. |

## Installation

### App Store (Recommended)
1. Download **Steel Trading Desk** from the iOS or Mac App Store.
2. The app is a Universal Purchase; buy once, use on all your devices.

### Build from Source
1. Clone the repository: `git clone https://github.com/ghostintheprompt/steel-trading-desk.git`
2. Open `Steel_Trading_Desk.xcodeproj` in Xcode.
3. Select the **Steel_Trading_Desk** scheme.
4. Target **Any iOS Device** or **My Mac** and press `Cmd + R`.

## Usage

1. **Analyze:** Perform technical analysis on your primary brokerage platform (ThinkOrSwim, Schwab, etc.).
2. **Input:** Feed the current chart state (Price, Volume%, VIX, Arrow) into the **Manual** tab.
3. **Validate:** Check the **Desk** or **VXX** dashboards for setup validation and signal strength.
4. **Prompt:** Use the **Prompt Coach** to copy pre-filled analysis prompts into ChatGPT or Claude.
5. **Execute:** Make your decision and execute manually on your primary platform.
6. **Manage:** Monitor active risk with the **Live** tab and follow close-management alerts.

## Privacy Statement

**Local-only. No telemetry. No bullshit.**
Steel Trading Desk does not collect, store, or transmit any of your personal information or trading data. All data entered manually remains in your local storage and is deleted when the app is removed.
